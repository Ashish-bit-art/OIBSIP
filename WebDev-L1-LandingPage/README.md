
# Nova Studio - Landing Page

## Project Overview

Nova Studio is a modern and responsive creative
digital agency landing page developed as part of
the Oasis Infobyte Web Development Internship.

The website introduces a fictional digital agency
that provides website design, branding and
development services.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries
- Google Fonts

## Features

- Sticky navigation bar
- Responsive hero section
- About section
- Services section
- Why Choose Us section
- Testimonials section
- Contact section
- Footer with social links
- Responsive mobile layout

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. View the website in your browser.
