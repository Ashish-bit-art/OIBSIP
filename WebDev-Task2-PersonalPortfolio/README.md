# Ashish Kumar — Personal Portfolio

A modern, responsive personal portfolio website showcasing professional experience, technical skills, selected project work and contact details.

## Built with
- HTML5
- CSS3 (custom properties, Flexbox, Grid and responsive media queries)
- Vanilla JavaScript for mobile navigation and theme switching
- Google Fonts (DM Sans and Manrope)

## Features
- Responsive navigation with mobile menu
- Five selectable colour themes: Midnight, Ocean, Forest, Violet and Light
- Theme preference saved in browser local storage
- About, skills, experience, projects, education and contact sections
- Smooth scrolling and responsive layouts

## Run locally
1. Extract the ZIP or clone the repository.
2. Open this folder in Visual Studio Code.
3. Open `index.html` with Live Server, or open the file directly in a browser.
