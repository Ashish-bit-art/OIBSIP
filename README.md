## 🌐 Project Details

### 1. Landing Page – Level 1, Task 1

**Objective:** Develop a visually attractive and responsive landing page for a creative digital agency.

**Features:**
- Fixed or sticky navigation bar.
- Hero section with headline and call-to-action buttons.
- About and Services sections.
- Consistent colour palette and typography.
- Responsive layout for desktop, tablet and mobile.
- Professional footer and navigation links.

**Technologies:** HTML5, CSS3

**Project Folder:** `WebDev-L1-LandingPage/`

### 2. Personal Portfolio Website – Task 2

**Objective:** Create a professional personal portfolio showcasing my technical skills, professional experience, projects, education, and contact information.

**Features:**
- Professional introduction and hero section.
- About Me section.
- Technical skills and technologies.
- Professional experience.
- Featured project showcase.
- Education and contact information.
- Responsive navigation and mobile layout.
- Smooth scrolling between sections.
- Multiple professional colour themes.

**Project Folder:** `WebDev-Task2-PersonalPortfolio/`

### 3. Temperature Converter Website – Task 3

**Objective:** Build an interactive temperature conversion tool.

**Planned Features:**
- Convert Celsius to Fahrenheit.
- Convert Fahrenheit to Celsius.
- Optional Kelvin conversion.
- Numeric input validation.
- Real-time conversion results.
- Responsive user interface.

**Technologies:** HTML5, CSS3, JavaScript

**Project Folder:** `WebDev-Task3-TemperatureConverter/`

## ▶️ How to Run Projects

Follow these steps to run any project locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/Ashish-bit-art/OIBSIP.git
   ```

2. Open the repository folder in Visual Studio Code.

3. Navigate to the required project folder.

4. Open `index.html` in your browser or use the VS Code Live Server extension.

5. Explore the project and test its functionality.
